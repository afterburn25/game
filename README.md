# Stellar Continuum

Public development repository for **Stellar Continuum**, an original real-time space civilization strategy game.

**Naming status:** Stellar Continuum is the canonical working title. Commercial trademark/domain clearance is still pending; see [`docs/BRANDING.md`](docs/BRANDING.md).

## Current development

Version: `0.0.6-dev.1`

Engine: Godot 4.7.2 .NET / C# (`net8.0`)

New campaigns begin on **January 1, 2050** with the player and normal major civilizations pre-warp. A small number of distant old powers begin already spacefaring but are non-expansionist and neutral unless provoked.

The current code is still a prototype of the pre-warp era. The canonical design direction is now broader: a human-like 2050 start is expected to include substantial orbital infrastructure, a permanent lunar presence, and a young Mars colony, followed by meaningful solar-system development before practical interstellar expansion.

### Research — current prototype vs canonical direction

The `0.0.6-dev.1` gameplay build still uses a temporary fixed research progression in which technologies consume accumulated science and can require completed infrastructure.

That prototype is **not** the final research architecture.

The canonical design is now Stellar Continuum's **Adaptive Research System**:

- the universe contains a broad Technology Possibility Graph
- the player never sees the complete future graph
- each civilization sees only technologies it currently understands or has reason/evidence to investigate
- visible branches can appear or change because of needs, basic science, environment, warfare, discoveries, alien contact, captured technology, and other legitimate evidence
- similar capabilities can be achieved through different technological implementations
- the same species can develop radically different technology trees across different campaigns
- foreign technology is not automatically usable or instantly unlocked

The player-facing research economy is built around:

- **Research Points (RP)** — generated by Research Labs and applied to active projects
- **Research Pressure** — contextual need/evidence that can gate certain technologies
- **Research Labs** — effective scientific capacity; projects require minimum assignable lab capacity
- **natural concurrency** — multiple projects can run at once whenever enough labs are available, with no arbitrary fixed research-slot cap

The first public design seed contains 244 normal/public possibilities across 15 domains and 59 research-pressure types. It is stored under [`data/research/v1/`](data/research/v1/) and is machine-validated in CI.

See [`docs/ADAPTIVE_RESEARCH_SYSTEM.md`](docs/ADAPTIVE_RESEARCH_SYSTEM.md) and [`docs/RESEARCH_ECONOMY.md`](docs/RESEARCH_ECONOMY.md).

### Construction

Construction projects consume accumulated industry. Current prototype projects include:

- Planetary Research Network — increases science output.
- Industrial Automation Program — increases industry output.
- Orbital Launch Complex — required before Orbital Industry can be researched.
- Orbital Shipyard — requires Orbital Industry.
- Warp Test Facility — requires Warp Field Control and must be completed before the Prototype Warp Drive can be researched.

This current progression chain remains prototype gameplay. Future construction/research prerequisites must be reconciled with the adaptive capability/possibility system rather than preserving the fixed chain simply because it exists in 0.0.6.

## Controls

The following controls describe the current `0.0.6-dev.1` prototype and will change as proper player-facing UI replaces keyboard/debug interaction:

- `Space` — pause/resume
- `1` / `2` / `3` / `4` — simulation speed
- `T` — cycle available prototype research
- `R` — start selected prototype research
- `C` — cycle available construction
- `B` — begin selected construction project
- left click — inspect astronomical target
- right click — order scout after warp capability
- `Shift` + right click — order colony ship after warp capability
- mouse wheel — zoom
- middle mouse drag — pan
- `N` — generate a new 2050 campaign
- `F6` — autosave
- `F8` — export diagnostics/support bundle

Save format v6 persists construction completion/progress in addition to the calendar, prototype research, civilization stages, fleets, colonies, economy, and fog-of-war knowledge.
