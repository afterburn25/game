## Player-facing scope

New Player games use 500 systems selected from the pinned HYG v4.1 catalogue.
The sample covers the Solar neighborhood out to 40.7186 light-years, not the entire
Milky Way. This implements the stated nearby-sample assumption while the optional
whole-galaxy versus local-neighborhood question remains unanswered. No real stars
are stretched across fictional spiral arms. The catalogue contains 50 proper names
and 450 actual catalogue designations. Unknown spectral types remain unknown.

Catalogue coordinates and names are fixed across seeds. Generated planets, resources,
civilizations and alien homeworlds remain fictional game content. Humans begin on
Earth in Sol; the authored Solar System is retained. Each other species receives a
naturally viable homeworld while retaining that system's catalogue identity.

The setup flow now has portrait choices on the left and the selected
species' biography, strengths, limits and environmental statistics on the right.
Generation receives the selected species ID through the existing session service.

## Distance and map contracts

HYG J2000 equatorial XYZ directions are normalized to catalogue parallax distance and
converted from parsecs to light-years. Sol is exactly zero. Reference distances from
this historical source are Proxima 4.23 ly, Alpha Centauri A/B (Rigil Kentaurus) 4.32 ly,
Barnard's Star 5.95 ly and Sirius 8.60 ly. These are approximate pinned-source values,
not claims of current Gaia accuracy. Missing distances are excluded, not fabricated.

`InterstellarDistance` owns 3D pair/fleet separation. Physical depth persists alongside
the flat chart coordinates. Lane lengths, range, fuel, travel progress, sensor reach,
opportunity displays and nearby/homeworld placement use physical separation. Transit
draws the 2D projection of physical progress. Missing legacy depth keeps the previous
flat metric, including its numeric precision. Saves retain their original system count;
100-system campaigns are never silently regenerated into 500.

Presentation alone uses a 14x local coordinate scale and fits actual bounds plus padding
to 720p/1080p. Picking, pointer-anchored zoom and territory/fog projection share the
same transform. Galaxy overview provides a deep-field background; the regional view
uses local stars, clusters and nebulae. Existing regional point-star rendering and
ordinary 2D solar-system sun appearance are retained. The distant galactic centre is
outside this sample; legacy global profiles retain their hidden-core rules.

The lane backbone was reduced from cubic to quadratic construction for 500 systems.
Existing bounded graph/route caches are retained. There is no per-star 3D sun node on
the regional map. Territory geometry is bounded independently of the physical units.

## Data provenance and packaging

See `data/astronomy/README.md` and the JSON's embedded source URL, SHA-256 and license.
The derived catalogue is CC BY-SA 4.0 with Astronexus attribution. It is embedded into
Game.dll so launch working directory and loose-file cleanup cannot remove it.
The Windows package includes `STAR_CATALOGUE_CREDITS.md`. Full source CSV is an
untracked local download; the maintained importer accepts that pinned input and can
verify generated bytes without rewriting the output. The JSON has LF attributes for
reproducible verification on Windows and Linux.
