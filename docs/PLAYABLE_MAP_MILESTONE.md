# Playable Map Milestone

New campaigns generate a compact map of **100 star systems**. Earth in Sol remains the Human opening position. Existing campaigns keep the systems saved with them, so a player never loses a campaign when this map profile changes.

The map is the primary play surface. The left-side navigation opens a full operations page for Research, Industry, Ships, Exploration, Colonies, Logistics, Relations, or Campaign management. Closing the page immediately returns to the map.

This milestone deliberately keeps the early playable area small enough to tune scouting, colonization, economy, and first contact before expanding map scale.
